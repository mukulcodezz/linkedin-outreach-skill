# DM Constraints & Rules

## Length
| Message | Words |
|---|---|
| Nurture first DM | 80-120 |
| Pitch variant | 100-130 |
| Follow-up | 30-70 |
| Reply | match theirs |
| Comment | 1-3 sentences |

Count before output. Trim if over.

## Format
- Short paragraphs, max 3 sentences each.
- Blank line between paragraphs.
- No bullets, no bold/italic in the message (LinkedIn ignores markdown).
- Greeting on its own line: `Hi [Name],`
- Natural close on its own line.

## Content
**Must include (DM):** personalized relevance line from a real profile signal; warm close.
**Pitch variant adds:** their pain + your offering as an OUTCOME (config.md §2) + 1 proof point (config.md §3) + one soft CTA.

**Forbidden everywhere:** emojis, links, price (first DM), self-praise ("best/leading/#1"), multiple CTAs, hollow flattery, "hope this finds you well", "explore synergies". (Full list: `tone_checker.md`.)
**Forbidden in nurture DM:** any pitch, proof stats, or call/meeting ask.
**Forbidden for Cold / Tier C:** the pitch variant entirely.

## Opener (config.md §7)
| Situation | Opener |
|---|---|
| Just connected (~within a week) | fresh opener |
| Older / unknown | safe older-connection opener |
| Trigger present (new job, anniversary) | fold it in |

Never start with the company name. Greet the person first.

## Pre-Output Checklist
- [ ] Length in range?
- [ ] Personalized (not generic)?
- [ ] No emojis/links?
- [ ] No self-praise/flattery?
- [ ] Pitch variant: one proof point only, one CTA?
- [ ] Cold/Tier C → nurture only?
- [ ] Passes `tone_checker.md`?
