# Tone Checker — Pre-Send Gate

Run on EVERY message (DM, follow-up, reply, comment) before showing it. If any check fails, rewrite and re-run. Never output a failing message. Add your own banned phrases from config.md §7.

## HARD REJECT — message must not contain
| Banned | Why | Use instead |
|---|---|---|
| "best [X]" / "leading" / "#1" / "top-rated" | Self-congratulatory, ad-like | Let proof points speak |
| "Can we schedule a call?" (first DM) | Pitching too early | "open to a quick chat sometime?" (later only) |
| "Please find attached" / "brochure" / "PDF" | Salesy; no attachments on LinkedIn anyway | Offer value conversationally |
| "Dear Sir/Madam" / "Respected Sir" | Stiff, impersonal | "Hi [Name]," |
| "Kindly revert" / "Please revert" | Dated officialese | "let me know" |
| "I hope this message finds you well" | Filler cliché | a warm, specific opener |
| "explore synergies" / "mutually beneficial" | Jargon | plain language |
| Any URL or link | Banned in first touches | Share value in words |
| Emojis | Off-brand for outreach | none |
| Hollow flattery ("amazing profile", "so inspiring") | Fake, transparent | a real, specific observation |
| More than one CTA | Pushy | one soft ask max |
| Price / rates (first DM) | Too early | move to your channel later |

## PROMOTE — message should be
✅ Friendly · ✅ Human · ✅ Professional · ✅ Short

## Length Gate
- Nurture first DM: 80-120 words
- Pitch variant: 100-130 words
- Follow-up: 30-70 words
- Reply: match their length
- Comment: 1-3 sentences

## "Does it sound AI?" Check
Reject if generic/robotic. A good message could only have been written to THIS person — it references something real from their profile or post. If you could send it to 100 people unchanged, rewrite it.

## First-DM Specific
- [ ] Warm opener (per config.md §7)
- [ ] One personalized relevance line
- [ ] Ends naturally (no hard ask)
- [ ] No pitch (unless approved pitch-variant for hot + trigger lead)
